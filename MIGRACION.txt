================================================================================
GUIA RAPIDA DE RESTAURACION Y PUESTA EN MARCHA (MIGRACION DE SISTEMA OPERATIVO)
Proyecto: ComplexIndexV2 (ELI)
================================================================================

Este paquete contiene TODO lo necesario para levantar el proyecto en un nuevo
sistema operativo (Windows, Linux o macOS) con su base de datos, reportes y
repositorio Git intactos.

CONTENIDO DEL PAQUETE:
- Codigo fuente completo (Counter, User, WordCounter, docs, locale).
- Base de datos completa (db.sqlite3) con empresas, workspaces, palabras y pericias.
- Archivos cargados y PDFs forenses (media/reportes y media/zip_uploads).
- Configuracion de entorno (.env).
- Repositorio Git (.git) en la rama 'rediseno-eli' con todo su historial.

NOTA IMPORTANTE:
El entorno virtual (.venv) NO se incluye en este paquete debido a que las
librerias compiladas de Python y sus rutas absolutas son exclusivas del sistema
operativo donde fueron creadas. Debe recrearse en el nuevo sistema siguiendo
estos simples pasos:

--------------------------------------------------------------------------------
1. ENTORNO WINDOWS
--------------------------------------------------------------------------------
Requisitos previos:
- Tener instalado Python 3.11, 3.12 o 3.13 (marcar "Add python.exe to PATH").
- (Opcional, para OCR de nuevos PDFs): Poppler y Tesseract (ver docs/setup/dependencies.md).

Pasos en PowerShell o CMD (dentro de la carpeta del proyecto):
  1) Crear el entorno virtual:
     python -m venv .venv

  2) Activar el entorno:
     .venv\Scripts\activate

  3) Instalar las dependencias de Python:
     pip install -r requirements.txt

  4) Iniciar el servidor:
     python manage.py runserver

  5) Abrir en el navegador:
     http://127.0.0.1:8000/

--------------------------------------------------------------------------------
2. ENTORNO LINUX / MACOS
--------------------------------------------------------------------------------
Requisitos previos:
- Python 3.11+ instalado junto con python3-venv.
- En Fedora: sudo dnf install poppler-utils tesseract
- En Ubuntu/Debian: sudo apt install python3-venv poppler-utils tesseract-ocr

Pasos en la terminal:
  1) Crear el entorno virtual:
     python3 -m venv .venv

  2) Activar el entorno:
     source .venv/bin/activate

  3) Instalar las dependencias:
     pip install -r requirements.txt

  4) Iniciar el servidor:
     python manage.py runserver

  5) Abrir en el navegador:
     http://127.0.0.1:8000/

--------------------------------------------------------------------------------
3. USUARIOS Y ACCESO
--------------------------------------------------------------------------------
La base de datos db.sqlite3 ya cuenta con los siguientes usuarios configurados:
- admin (Superusuario)
- experto (Perito)
- normalito (Analista)
- auditor (Auditor)

Si no recuerdas la contrasena de algun usuario en el nuevo entorno, puedes
cambiarla instantaneamente con:
  python manage.py changepassword admin

O crear un nuevo superusuario:
  python manage.py createsuperuser
